# AI chat widget для веб-сайтов

Это будет встраиваемый AI-виджет для сайтов малого бизнеса. Добавляет на любой сайт чат-помощника, который отвечает на вопросы клиентов в реальном времени.

## Что это

Легковесный React-компонент, который можно встроить на сайт как отдельный элемент. Внутри чат с AI-ассистентом, который будет:
- Отвечать на вопросы клиентов **в режиме стриминга** (текст появляется постепенно, как в ChatGPT)
- Помнить диалог в рамках сессии
- При ошибке API (лимит, сбой сети) **переключается на форму заявки** -клиент не теряется, а оставляет контакт
- Кастомизироваться под бренд клиента (цвета, аватар, приветственное сообщение)

**Целевая аудитория:** малый бизнес (салоны, магазины, сервисы), у которых нет своего чат-бота, но есть потребность отвечать клиентам быстро.

## Стек, который буду использовать

- **React + Vite** - быстрый старт, HMR, современный тулинг
- **TypeScript** - типизация компонентов и API-ответов
- **Tailwind CSS** - стилизация без раздувания CSS
- **AI API** - OpenAI / Claude API для генерации ответов (стриминг через `ReadableStream`)
